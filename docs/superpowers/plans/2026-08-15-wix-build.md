# Wix Build Plan (Task B)

> Steps use checkbox (`- [ ]`) syntax for tracking. Suggested hour blocks assume a Day 1, 09:00 start, continuing into Day 2 — shift proportionally if your actual start time differs. Wix work is scheduled after the WordPress build is deployed (Day 2), so the design system is already locked in from real decisions, not guesses.

**Goal:** Ship the NOVA Studio landing page on Wix — visually consistent with the WordPress build, backed by a Wix CMS collection, with a consultation form wired through a Velo back-end module.

**Spec:** `../specs/2026-08-15-nova-studio-design.md` §5, §6, §7
**Starter code:** [`wix-velo-starter/`](../../../wix-velo-starter) — `backend/consultation.jsw`, `page-code-example.js`, `cms-collections.md`.

---

### Task 1: Site, Dev Mode, design tokens — *Hour 1–2 (parallel kickoff) + Hour 26.5–27*

- [ ] Create a new Wix site (Editor or Studio)
- [ ] Turn on **Dev Mode** (top menu → Dev Mode → Turn on Dev Mode)
- [ ] Set Site Theme colors to match WP exactly: `#1E1B4B` / `#14132B` / `#FAF9F6` / `#FF6B4A`
- [ ] Set Site Theme fonts: heading Sora/Poppins, body Inter (confirmed available in pre-test prep)

### Task 2: Build all 8 sections — *Hour 27–31.5*

- [ ] Hero: same headline/subhead/CTAs as WP, layout adapted to Wix's section paradigm
- [ ] Services: 3 cards, same copy as WP
- [ ] Why NOVA: 3–4 reasons, same copy as WP
- [ ] Portfolio: 3–4 project cards, same copy/images as WP
- [ ] Process: 4+ steps, same copy as WP
- [ ] Testimonials: 2+ testimonials, same copy as WP
- [ ] Final CTA + Footer, same copy/links as WP

### Task 3: CMS collections + consultation form UI — *Hour 31.5–33.5*

- [ ] Create collection `ConsultationRequests` per schema in `../../../wix-velo-starter/cms-collections.md`
- [ ] (Optional) Create `Testimonials` / `Portfolio` collections if going the no-code Dataset route for those sections
- [ ] Build the "Book a Consultation" form: Name, Email, Company, Message inputs + Submit button
- [ ] **Do not** wire this form via the no-code "Connect to CMS" dataset panel — it must go through Velo (see Task 4)
- [ ] Set `ConsultationRequests` collection permissions to Content Manager only (no visitor read/write)

### Task 4: Velo backend wiring — *Hour 33.5–35.5*

- [ ] Create `backend/consultation.jsw`, paste from `../../../wix-velo-starter/backend/consultation.jsw`
- [ ] Adjust the collection name/field keys in the code if they differ from Task 3's actual schema
- [ ] Add page code from `../../../wix-velo-starter/page-code-example.js`, rewiring `$w('#...')` IDs to match your actual element IDs
- [ ] Test end-to-end: submit the form, confirm a new item lands in `ConsultationRequests` (CMS panel → view data)
- [ ] Test the duplicate-submission guard (submit the same email twice within a day, confirm the second attempt doesn't create a duplicate row)

### Task 5: Optional CMS depth, mobile pass, consistency check — *Hour 35.5–37.5*

- [ ] (Optional) Wire Testimonials/Portfolio sections to their collections via Repeater + Dataset
- [ ] Open **Mobile View** in the Wix Editor and do a manual layout pass per section — Wix does not auto-reflow like CSS Grid
- [ ] Compare WP and Wix side by side (screenshots or two browser windows) — colors, fonts, section order, copy
- [ ] Log any discrepancy found (and how it was resolved) in `../SYNC.md`

### Task 6: Publish, credentials, screenshots — *Hour 37.5–38.5*

- [ ] Publish the site → copy the live URL
- [ ] Invite the evaluator as a Collaborator (Site → Collaborators → Invite) — not your personal Wix account password
- [ ] Screenshot desktop and mobile views of the full page
- [ ] Draft/finalize **Design Notes** and **Technical Notes** for the Wix half (see spec §7)
